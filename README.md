# WifiCrush

Landing page for **WifiCrush**, a jailbreak tweak for rootless iPhones (iOS 15 and later) that keeps you on the Wi-Fi you love while it is strong, moves to a stronger network or to 4G/5G when it fades, and comes back by itself.

Live page: https://pitroytech.github.io/wificrush-landing/

The page is a simulation of WifiCrush's rules next to how iOS usually behaves. It does not scan or control any network.
